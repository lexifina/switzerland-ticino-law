# Art. 62 b) con il sistema maggioritario
1 Ha luogo con il sistema maggioritario l'elezione complementare:
a) di un membro delle autorità elette con il sistema proporzionale;
b) dei membri di autorità elette con il sistema maggioritario.
2 Le elezioni complementari si tengono secondo le norme delle elezioni generali.
3 La data delle elezioni complementari comunali con il sistema maggioritario è fissata dal Municipio.
